# Console Calculator Project (Lv1 → Lv3 기능 확장형 계산기)

자바 학습을 위해 진행한 **콘솔 기반 계산기 프로젝트**입니다.

---

## 개발 환경

| 항목 | 내용 |
|-------|------|
| Language | Java |
| IDE | IntelliJ |
| 버전 | JDK 17+ |
| 실행 방식 | 콘솔 입력 기반 실행 |

---

## 레벨별 목표 요약
- `Lv1` : 단일 클래스, 절차형 흐름
- `Lv2` : `Calculator 분리`, 컬렉션 적용
- `Lv3` : `Enum`, `Stream`, `Generics` 적용

| 구분 | 주요 기능                                   | 학습 포인트 |
|-------|-----------------------------------------|------------|
| **Lv1** | 한 class에서 구현하기, 기본 사칙연산, 연속 계산, exit 종료 | `while`, `switch`, `Scanner` |
| **Lv2** | 컬랙션화 및 메서드 구현하기, 연산 결과 저장, 수정/삭제, 예외 처리 | `ArrayList`, `try-catch`, `메서드 분리` |
| **Lv3** | 제네릭, 실수 계산, 필터링, Enum, Stream           | `Generics`, `Stream`, `Enum` |

---

## 실행 흐름

1. 첫 번째 숫자 입력
2. 연산 기호 입력
3. 두 번째 숫자 입력
4. 결과 출력
5. 이후 동작 선택
    - 이어서 계산
    - 저장값 수정
    - 저장값 삭제
    - 숫자 필터링(Lv3)
    - 종료

## 레벨 상세

### Lv1 (기본 계산기)

- `switch` 로 기호 처리
- 잘못된 연산자 입력 시 문구
- `exit` 키워드로 종료
- 연속 계산 가능 (result → num1)

→ **“기본 흐름 제어와 입력 처리, 틀 구상”에 집중**

---

### Lv2 (저장 기능 + 예외처리)

- `Calculator` 클래스 분리 (메서드 활용)
- `ArrayList` 로 결과 저장 (컬랙션 활용)
- 저장값 수정 / 삭제 기능 (게터, 세터 활용)
- `InputMismatchException` 처리 (try-catch 예외처리 활용)

→ **“메서드 분리, 예외 처리, 메서드 기능 구현” 복습**

---

### Lv3 (제네릭, Enum, Stream 적용)

- `D extends Number` (제네릭 활용)
- `Enum` 으로 연산자 관리 → 유지보수성 향상
- `Stream + filter + sorted` (스트림활용 기능 추가)

→ **도전기능 과제 전부 구현해보기에 집중**

## 향후 개선점

- 메서드 간에 이뤄지는 예외부분 처리 필요
- 중복되는 코드 및 지저분한 코드 리팩토링 필요

---

## 느낀 점

> Lv1 → Lv3 단계별 확장을 통해  
> 단순 동작만 한다는 개념이 아닌 원리를 배울 수 있었고 자바가 왜 객체지향이고 유지보수성이 뛰어난지 느낄 수 있었다.
> 다음 과제 진행간에는 진행흐름을 빠르게 파악하고 예외를 처리하는 구간을 잘 짚고 넘어가야겠다.
